# 变更记录（Changelog）

AgentJ 的版本变更记录。`README.md` 只保留项目简介、高层特性概览、结构与快速上手；
**详细特性清单**归档在本目录，**用户可见特性**见 [`docs/guide/`](../guide/)。

## 归档约定

- 每个次版本（minor）一个文件：`v0.<minor>.md`；同一次版本下的补丁号（patch）作为该文件内
  的独立小节，例如 `v0.1.md` 收录 `0.1.0` / `0.1.1`。
- 条目按 [Keep a Changelog](https://keepachangelog.com/) 风格分节：
  `Added`（新增）/ `Changed`（变更）/ `Fixed`（修复）/ `Removed`（移除）。
- 触及协议 wire 契约的版本标注 `PROTOCOL_VERSION` 变化；纯前端/无协议变更的版本显式标注。
- 每个小节标注发布类型：**功能**（minor）/ **修复**（patch）。
- 新增条目追加到对应次版本文件；新次版本另建文件并更新下方索引。
- **版本号不随特性/修复自动递增**：当前版本默认保持 `0.1.0`，仅当用户主动要求变更版本号时
  才更新（细则见 [`AGENTS.md`](../../AGENTS.md) 「版本与提交」）。
