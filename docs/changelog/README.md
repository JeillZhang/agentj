# 变更记录（Changelog）

AgentJ 各版本的详细变更记录。`README.md` 只保留项目简介、高层特性概览、结构与快速上手；
**详细版本变更**与**逐版本特性记录**统一归档在本目录，**用户可见特性**见
[`docs/guide/`](../guide/)。

## 归档约定

- 每个**次版本（minor）**一个文件：`v0.<minor>.md`；同一次版本下的补丁号（patch）
  作为该文件内的独立小节，例如 `v0.24.md` 收录 `0.24.0` / `0.24.1` / `0.24.2`。
- 条目按 [Keep a Changelog](https://keepachangelog.com/) 风格分节：
  `Added`（新增）/ `Changed`（变更）/ `Fixed`（修复）/ `Removed`（移除）。
- 触及协议 wire 契约的版本标注 `PROTOCOL_VERSION` 变化；纯前端/无协议变更的版本显式标注。
- 每个小节标注发布类型：**功能**（minor）/ **修复**（patch）。
- 新增条目追加到对应次版本文件；新次版本另建文件并更新下方索引。
- 版本早期（v0.1–v0.10）历史据 git 提交与 `docs/superpowers/{specs,plans}` 设计/计划文档整理。
