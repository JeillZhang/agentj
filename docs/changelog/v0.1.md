## 0.1.0 —— 内核 + IPC 协议契约（功能）

### Added
- **内核架构**（`agentj-core`）：Kernel 消息总线 + 模块 trait 注册表 + `KernelContext`。
- **IPC 协议契约**（`agentj-protocol`）：JSON-RPC 2.0 信封 + 错误码 + 方法类型；
  JSON Schema 生成（`schemas/*.json`）+ 方法注册表（`protocol/methods.json`）+
  漂移门禁；人类可读规范（`docs/specs/ipc-protocol.md`）；TypeScript 绑定测试。
- **内置工具**（`agentj-tools`）：bash / glob / grep / read / write + ToolExecutor
  （进程组隔离 + 超时杀进程组）。
- **模型提供方**（`agentj-model`）：OpenAI-compatible SSE / OpenAI Responses /
  Anthropic Messages / Mock（三线 wire-format）。
- **MCP 客户端**（`agentj-mcp`）；**上下文管线**（`agentj-context`）；
  **配置合并**（`agentj-config`）；**内存会话存储**（`agentj-session`）+
  archive/delete 生命周期 + 恢复快照契约。
- **Agent 循环**（`AgentLoop` 流式 API）。
- **CLI**（`agentj-cli`）：`run` / `serve [stdio]`。
- **CI 流水线**：GitHub Actions（单元 / 冒烟 / E2E）。

### Changed
- 三份独立实现计划（v0.1 core / v0.3 ecosystem / v0.4 commercial，2026-08-16 重编号）。
