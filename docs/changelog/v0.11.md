## 0.11.1 —— 验收修复（修复）

### Fixed
- **B-001**：`RpcClient.initialize` 默认使用 `PROTOCOL_VERSION`。
- **B-002**：从浏览器 SDK 入口移除 `TcpTransport`，避免打包 `node:net`。
- **B-003**：`resolveWsUrl` 在 envUrl 后追加 token。
- **B-004**：TUI `formatUsage` 对齐 `UsageInfo.prompt_tokens`（runview + footer 测试）。
- **B-005**：`ConnectionManager` 在鉴权错误时停止重连。
- **B-006**：TUI mock kernel 使用 `prompt_tokens`。
- **B-007**：dashboard 提示显示正确端口。
- **B-008**：`ModelSelector` 使用配置的 `default_model`。
- **B-009**：TUI 测试包裹 `act` 消除警告。

## 0.11.0 —— agentj-ui monorepo（功能）

### Changed
- `web-dashboard` → `agentj-ui/apps/web` 重命名；`bindings` 迁入
  `agentj-ui/packages/protocol`；新建 `packages/sdk` 共享 SDK。
- 三端同源消费 `@agentj/sdk` + `@agentj/protocol`，后端零改造。
- npm workspaces `apps/*` + `packages/*`。

### Added
- Web 对齐：方法常量化 / `?token=` 透传 / `protocol_version` 同源 / 会话收藏 /
  composer / `$/progress` / 审批对话框 / usage。
- TUI 全功能：Bun + `@opentui/react`，连接管理 / 会话列表 / 新建 / 继续 / composer 多行 /
  `@` 补全 / `/` palette / 流式渲染 / 审批模态 / 模型只读 / 主题 / usage / 优雅退出 +
  mock WS e2e。
- Desktop：Tauri v2 壳套 `apps/web` 产物，四件套 deb/AppImage/dmg/msi，
  `check-artifacts.sh` 校验。

### Changed
- G7/G8/WebSocket 等 0.10 能力全保留。
