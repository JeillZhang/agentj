## 0.14.0 —— 三栏工作台（功能）

### Added
- `WorkspaceShell` 三栏布局：Sessions/Files 左栏 + 会话中栏 + 运行详情右栏。
- `SplitPane` 拖拽/键盘/双击 + `layoutStore` 宽度持久化 + `<1024` 右抽屉。
- 右栏 `RightPanel` = `TodoPanel` + `ChangeList`（unified diff 展开，
  `deriveChanges` 从 write tool_call 半数据派生）。
- composer 模型/Agent/熵变三选择器（`OptionPopover` + `ComposerOptions`，互斥 +
  localStorage 持久化）。
- `AskQuestionCard` 模型提问卡片（可折叠 + 问答记录）。
- `TopbarMenu` 顶栏化（连接设置/继续会话/收藏/排序/过滤/设置/帮助 + demo 开关）。
- `demoData` 顶栏开关驱动 TODO/文件树/变更/提问卡 demo 数据。

### Changed
- tokens 19 → 24 keys + `LAYOUT` 常量块（kebab→camel radius 迁移）。
- 前端（React/Bun/Tauri）全部收敛于 `agentj-ui/` 内，不向 Rust workspace 注入前端产物。
