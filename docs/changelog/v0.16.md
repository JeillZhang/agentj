## 0.16.2 —— 远程访问修复（修复）

### Added
- `serve --port` / `dashboard` 新增 `--host`（默认仍 127.0.0.1 本机信任；`--host 0.0.0.0`
  支持局域网/远程直连）；`dashboard` 补齐 `--token`；非回环绑定无有效 `--token`（含空串）
  时输出暴露告警；启动日志打印实际 `ws://<host>:<port>/ws`（IPv6 自动加方括号、端口取
  实际绑定值）。

### Changed
- Web `resolveWsUrl` 页面地址派生（无 `VITE_AGENTJ_WS_URL` 时取页面 `host:4096`，
  https 自动 wss，`tauri.localhost` 保持明文回环）；「连接设置」手动连接持久化到
  `agentj.connection`（刷新自动恢复并重连、弹窗回填）。

### Verified
- 修复远程打开页面仍连 `ws://127.0.0.1:4096/ws`、刷新丢失指定 IP 的问题；
  Rust 553 → 560 / sdk 37 → 43 / web 231 → 239。
