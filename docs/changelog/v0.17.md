## 0.17.2 —— 界面修复（修复，用户直报 2 项）

### Fixed
- **显示设置字号**：由四档枚举（小/中/大/特大 × 4 区，16 个单选纵向堆叠致弹窗过度拉伸）
  改为逐区像素数值——`displayPrefsStore` 字号字段转为 px（`FONT_SIZE_LIMITS` 校验：
  对话 12–24 默认 15、左右栏 10–20 默认 13、代码 10–20 默认 12；clamp+取整；旧
  `sm/md/lg/xl` 按区迁移），`SettingsDisplayPanel` 每区一行「标签 + range 滑杆 +
  number 输入 + px」（draft 受控，blur/Enter 提交夹取），行高/密度选项横排；
  `WorkspaceShell` 直接注入 `${px}px`。
- **弹窗边框/四角可缩放**：`ModalDialog` 新增 `.aj-dialog-frame`（承载尺寸/位置，首次
  拖拽冻结 fixed 矩形）+ 8 个指针手柄（4 边 + 4 角，hover accentTint + 方向光标）；
  新 `dialogResize.ts` 纯函数 `resizeRect`（对边锚定、最小 320×200、视口 8px 边距夹取、
  可选 per-dialog `minWidth/minHeight`，设置弹窗下限 560px）；`.aj-settings` 宽度修饰
  移至 frame，`.aj-dialog-card` 基类规则不变（`ApprovalDialog` 不受影响）。
- 复核修复波（Oracle 评审 6 项）：`resizeRect` per-dialog 下限以视口上限夹取 + 增长按
  锚定边可用空间夹取（原点零漂移）、新增 `clampDialogRect` + window resize 重夹取、
  非主键/pointer capture 守卫、旧枚举 `hasOwnProperty` 校验、手柄外移避让滚动条。

### Verified

## 0.17.0 —— 六项增强（功能）

### Added
- **对话代码块卡片化**：`rehype-highlight`（hljs common 语言集，`.hljs-*` 映射现有语义色
  变量）+ 新 `CodeBlockCard`（`figure > figcaption + pre`：左上折叠/展开保留 header +
  语言标签、右上复制；折叠不卸载，流式追加保持折叠态）+ 新 `copyText`
  （`navigator.clipboard` → textarea/`execCommand` 降级链 + 失败瞬态，http 局域网非安全
  上下文可用）。
- **显示设置**：新 `displayPrefsStore`（`agentj.displayPrefs`）+ `SettingsDisplayPanel`
  （设置「显示」tab + 「恢复默认」）+ 新 `displayPrefs.css` 覆盖层（最后导入、`var()`
  fallback 保值）+ `WorkspaceShell` inline `--aj-font-*` / `--aj-lh-conv` /
  `data-density` + `App` effect 写 `documentElement[data-reduced-motion]`。
- **文件树源码/db 图标**：`fileIcons.ts` 扩展主流源码扩展名（rs/go/py/java/c/cpp/cs/rb/
  php/kt/swift/scala/lua/dart 等）+ 新 db 类（`Database`）+ 文件名特例
  （Dockerfile/Makefile/CMakeLists.txt → code）+ `.file-icon--db` 配色。
- **会话列表菜单**：新 `SessionListMenu`（左栏清理按钮改为 ⋯ 菜单：`清理所有会话…` 打开
  既有确认弹窗、无可删禁用；`过滤 ›`/`排序 ›` 悬停向右飞出二级 `menuitemradio`，镜像
  TopbarMenu 延迟/桥接/Esc 分层/键盘；直写 `sidebarPrefsStore`）——设置弹窗「会话列表」
  tab 整体移除。
- **项目编辑**：`projectStore` 扩展 `workDir/isDefault/defaultModel/defaultAgent` 可选字段
  （零迁移）+ `updateProject`（`isDefault` 互斥 + 修复 rename 不通知）/`deleteProject`
  （Inbox 守卫 + 会话归属回退 + 计数）+ `ProjectDefaults`；新 `ProjectEditDialog`
  （名称 / 工作目录绝对路径校验 / 默认项目 / 默认模型 / Agent）+ composer picker 每行编辑
  按钮 + `session/new` 首次携带 `project_root`（工作目录打通）+ 项目默认模型/Agent 随切换
  应用。
- **设置「项目」tab**：`SettingsProjectPanel`（全局默认项目 + 新项目工作目录预填 + 项目列表
  名称/工作目录/默认徽标/编辑/删除，Inbox 不可删、删除确认展示会话回退数）+
  `ModalDialog` 模块级模态栈（嵌套弹窗仅栈顶响应 Esc/遮罩）。
