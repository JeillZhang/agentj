## 0.18.1 —— token 统计位置与拆分修复（修复，用户直报）

### Fixed
- `Σ` 会话 token 读出从 composer 底栏（模型选项旁）移至输入框 header「deepseek-chat」
  模型 chip 右侧：`RunPanel` 新增 `.aj-composer__header-meta`（chip + 读出右对齐 +
  内部换行兜底，header `flex-wrap`）；`ComposerOptions` 移除 `usageTotal` prop 与
  `.comp-usage`（options.css 同步移除）。

### Changed
- 统计拆分输入/输出：`Σ 2.5k · 输入 2k · 输出 500`（新 `tokenUsage.ts`：
  `formatTokenTotal` 迁出 + `formatUsageSummary` 摘要 + `formatUsageTitle` 精确
  tooltip/aria-label）。
- 实机 Playwright 15/15（位置 / chip 右侧 / 拆分 / tooltip+aria 精确值 / 390px
  无溢出 / 无控制台错误）+ Oracle 复核 PASS（a11y 明细 / meta 内部换行 / total 去重 /
  4 补测）；web 468 → 479 tests（46 files）。

## 0.18.0 —— 三项增强（功能，用户直报）

### Added
- **composer 75% 居中浮动**：`.aj-composer-card` `position: absolute; bottom: 16px;
  width: 75%; margin: 0 auto; max-height: calc(100% - 32px)`（layout.css 拆分全宽规则，
  特异性 (0,2,0) 承接 75%）；`--aj-composer-h`（`RunPanel` `useLayoutEffect` +
  `ResizeObserver` `borderBoxSize` 全盒高）驱动 `.aj-conv` `padding-bottom` /
  `scroll-padding-bottom`（= 高度 + 32px）→ 内容延伸至卡片底部（滚动穿透浮层）、
  滚动到底时末条消息停在输入框顶上方 ~16px；窄视口
  `min-width: min(340px, calc(100% - 16px))` + `.comp-tools` `flex-wrap: wrap` 两行兜底。
- **权限选择器**（逐次确认/自动允许）：`ComposerPrefs.permissionMode` +
  `agentj.composer.permissionMode`（`readEnum` 校验 + 跨标签 `storage` 同步 + bypass
  accent 边框提示）；bypass 时 `useApproval` 对当前会话 `$/permissionRequest` 自动
  `permission/respond allow`（不再弹窗；内核配置 deny / 路径越界仍强制拒绝；纯客户端能力）。
- **会话 token 总量**：`RunPanel` 聚合 usage entries（历史回放 + 实时逐轮恰好一条）→
  模型触发器右侧 `Σ 5.2k`（`formatTokenTotal`：k/M 一位小数、`.0` 修剪、999.95k 起
  进位 M；title 输入/输出明细；无用量隐藏）。
- 实机 Playwright 验证（75.0% 居中偏差 0 / 浮底 16px / 穿透 / 滚底对齐 / 权限跨标签
  双向同步 / 390px 无溢出）+ Oracle 复核 PASS（6 minor/nit 修复波 + 2 补测）；
  web 446 → 468 tests（45 files）。
