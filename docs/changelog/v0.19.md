# v0.19.x —— 内核托管 Web UI + 文件树状态补强

> 发布：0.19.0（2026-09-20，功能）
> 协议：`PROTOCOL_VERSION` 保持 **0.13.0**（无 wire 变更）；新增依赖 `tower-http`（fs/set-header）+ `uuid`（v4）

## 0.19.0 —— 两项（功能）

### Added
- **内核同端口静态托管**：`agentj-ipc` 新 `web` 模块（`WebConfig` + `build_router`）在
  `ws_router` 上 `nest_service("/assets", ServeDir)`（`Cache-Control: public,
  max-age=31536000, immutable`）+ `fallback_service(ServeDir::fallback(ServeFile(index.html)))`
  （根 `no-cache`、未知页面 200；`/ws`、`/login`、`/logout` 显式路由优先且不在门后——
  `Router::layer` 会波及 `/ws`，故两静态服务各自包裹 cache 层与登录门）。
- **混合鉴权登录门**：回环 peer / 未配置 token 直出；非回环 + token 且无有效 cookie →
  `302 /login?next=<同源相对路径>`（`safe_next` 只放行 `/` 开头且非 `//`，防开放重定向；
  错拼 `/assets/*` 仍 404）；内嵌登录页（无 JS）POST 校验后颁发不透明会话
  （`uuid`，内存 `RwLock<HashSet>`，重启即失效）经
  `Set-Cookie: agentj_session=<id>; HttpOnly; SameSite=Lax; Path=/`（会话 cookie 无
  `Max-Age`）；`/logout` 撤销 + `Max-Age=0`。
- **WS 第三鉴权通道**：有效会话 cookie + 同源 `Origin`（`origin_matches_host` 去 scheme
  比 Host）免 `?token=` / `initialize.token`；`serve_connection` 的 token 参数已属遗留，
  服务端为 cookie 通道装配 initialize 参数时注入 server token
  （`WsConnection::with_init_token` + `supply_initialize_token`）。
- CLI `serve` / `dashboard --web-dist <PATH>` 四级发现（显式 flag/env 无效即停并告警 →
  cwd `agentj-ui/apps/web/dist` → exe 相对两档）+ 启动打印 `http://<host>:<port>/`。
- 测试：`agentj-ipc` `web` 单测（静态/缓存头/SPA 落回/登录门/cookie 放行/伪造 cookie/
  dist 缺失/无 token 直出）+ `e2e_http_static`（断言 `/assets/*` 状态码并持有 stdout
  reader 防子进程 stdout 提前关闭）。

### Changed
- **文件树目录聚合状态**：`file/list` 目录 `git_status` 取后代最高优先级字母
  （`U>D>M>A>Unknown`，前缀 `"{dir}/"` 严格匹配，`srcx/` 不误伤 `src/`）；
  Web `FileTree` 目录行 `StatusCell` 渲染状态字母、移除冗余圆点。
