## 0.20.0 —— 四项（功能）

### Changed
- `serve_connection` 遗留 token 参数清理（`TcpIpcServer` 死 token 字段一并移除）；
  `WsServerState.token` / `WsQuery.token` / `?token=` / `initialize.token` 语义不变。

### Added
- **登录限流**：`agentj-ipc` 新 `login_limiter` 模块——按来源 IP 计数，第 5 次失败起
  锁定 30s、×2、封顶 900s；`429 + Retry-After`（秒，`ceil` ≥1）；锁定期不校验 token
  且新尝试升级锁定；成功清零；`idle_ttl` 1800s 懒淘汰；`max_tracked` 1024 淘汰；
  回环同样计数。`/login` POST 接线（`auth_routes` 透传 peer）。
- **版本探测与 SRI**：`apps/web/build/version-sri.ts` + `version-sri-plugin.ts`
  （`writeBundle` 生成 `dist/version.json`（product/protocol/build_time，单一真源 =
  sdk config）+ 入口 HTML 同源 script/stylesheet/modulepreload 注入 `sha384`
  `integrity`，本地引用缺失即构建失败；零新依赖）；内核 `WebConfig` 读取 `DistVersion` +
  `startup_warnings()`（缺失/不可解析/不一致三类启动警告，不阻断服务）+ 未鉴权
  `GET /version`（200 JSON + `Cache-Control: no-store`，显式路由优先于 SPA fallback）+
  `TcpIpcServer::web_config()`；CLI `serve` 启动打印 dist 版本警告；
  Web `ConnectionStatus` 版本行「版本 UI x · 内核 y」（不一致 `data-state="warn"` + `⚠` +
  warning 色）、`App` 消费 `initialize.server_info.version`、SDK barrel 导出 `VERSION`。
- **TUI Files 视图**：`files.ts` 纯函数（flatten/format/color/updateNode 等）+
  `files.tsx` `FilesView` + `useFileTree`（懒加载 `file/list` depth=1、stale-reply
  代际守卫、collapse 保留子树、refresh 根+已展开、会话切换清空重取、不持久化）+
  `sidebar.tsx` Threads/Files 切换（`f`）+ `app.tsx` 键位（`j,k,↑,↓` 移动 /
  `Enter,l,→` 目录开合 / `h,←` 收起或跳父级 / `r` 刷新）+ mock kernel `file/list` + e2e。
- 目录聚合状态字母色义：M→warning、A→success、U→textCaption、D→error。

### Verified
- Oracle 全量复核 PASS（无 must-fix）+ 修复波（TUI stale-reply 守卫 + 父级跳转 clamp +
  Web warn 色 CSS 契约测试）。
