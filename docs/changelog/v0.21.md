  park 到 files tab 按钮（`71245d5`）。

## 0.21.0 —— 四项（功能）

### Added
- **登录限流可观测性**：`agentj-ipc` `login_limiter` 在状态变化点发 tracing 事件
  （锁定**新触发** `warn`、成功登录 `info`、逐次失败/锁定期拒绝 `debug`）；
  `AtomicU64` 聚合计数经 `GET /version` 加性 `login_limiter` 块暴露
  （`attempts` / `failures` / `lockouts` / `blocked` / `locked_now` / `tracked_ips`，
  无 per-IP 明细）。
- **资产完整性**：构建期 `apps/web/build/version-sri*` 生成 `dist/asset-manifest.json`
  （`algorithm: "sha384"` + `assets: { "/path": "sha384-<base64>" }`，覆盖全部 Rollup
  bundle 产物含动态 chunk + SRI 注入后的 `index.html`；单遍哈希与 SRI `integrity`
  逐字节一致；排除 `version.json`/自身/`public/` 透传；键须为 `/` 开头规范路径）。
  内核 `WebConfig` 启动逐文件校验并并入 `startup_warnings()`（缺失/不可解析/不符/
  文件缺失，警告不阻断服务）；摘要进 `GET /version` 加性 `integrity` 块
  （`manifest_present` / `checked` / `mismatched` / `missing`）。
- **TUI Files 搜索**：`s` 进入搜索（`file/list { path: null, depth: 8 }` 单请求扁平
  索引 ≤2000 + 客户端过滤），可打印字符过滤（含 `f`/`n`，吞键）、`Backspace` 删末字符、
  `Esc` 非空清空/空退出、`Enter` 跳转（祖先自动展开）并选中目标、`r` 重建索引、
  `truncated` 显示 `· partial`。
- **Web 焦点作用域**：新 `useShortcutScope`（`activeElement` 在侧栏内、目标非可编辑、
  非 IME、无修饰键、无模态/菜单才生效）提供 `f`/`n`/`r`/`j`/`k`/`Esc`；文件树/会话列表
  roving tabindex 键盘导航；`ModalDialog` 开关焦点恢复（原元素卸载不恢复）。

### Changed
- CLI 日志订阅器改 `EnvFilter`（`RUST_LOG` 可配，未设默认 `info`，行为与 v0.20.0 逐字一致）；
  限流策略语义（429 / Retry-After / 锁定升级 / 清零）零变化。
- 展开状态经新 `filetree.json`（`$XDG_CONFIG_HOME/agentj/`）按本地项目键持久化
  （per-key ≤100、恢复 ≤50、失效路径静默跳过、陈旧键清理）。
- **Tab 保持原生**、composer 输入零误触。
