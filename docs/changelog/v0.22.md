# v0.22.x —— 限流指标导出 + 资产清单扩展/抽检 + TUI 服务端搜索 + Web 键位收口

> 发布：0.22.0（2026-09-25，功能）
> 协议：`PROTOCOL_VERSION` **0.13.0 → 0.14.0**（三处加性 wire）

## 0.22.0 —— 四项（功能）

### Added
- **限流指标导出**：`agentj-ipc` `login_limiter` 新增只读 `snapshot()` 投影
  （`ip` / `failures` / `locked` / `retry_after` / `last_seen`，排序 `locked desc →
  failures desc → ip asc`）；`web` 新增 `auth_required()` + 显式路由 `GET /metrics`
  （Prometheus 文本 `text/plain; version=0.0.4` + `Cache-Control: no-store`：聚合
  counters/gauges + per-IP series Top-50 截断 + `agentj_login_ip_series_truncated`
  指示 + `integrity` 摘要；回环/未配 token/有效 cookie 直出，非回环 + token 无 cookie →
  `401` 不重定向）。`/version` 既有契约零变化。
- **资产清单扩展 + 运行期抽检**：构建清单覆盖 dist 实目录全部部署文件（含 `public/`
  透传，bundle 键优先，排除 `version.json`/自身/隐藏文件）；`TcpIpcServer` 启动后
  60s / 8 文件游标轮转后台抽检（`SpotCheckConfig` 可注入），不符/缺失 `warn!`
  按路径去重；`/version` `integrity` 加性嵌套
  `runtime { rounds, checked, mismatched, missing, last_run_age_secs? }`。
- **`file/list` 服务端搜索**：加性参数 `query`（`path` 子树、忽略 `depth`、
  大小写不敏感子串、访问预算 `SEARCH_VISIT_LIMIT = 20000`）与结果 `total`
  （预算受限为下界）；rank 名称前缀 > 名称子串 > 路径子串、返回 Top-100。
- **Web 键位收口**：共享 `useRovingFocus`（`wrap` / Home-End）扩展并迁移
  TopbarMenu / SessionListMenu / SidebarTabs / SettingsDialog 四处
  （ComposerOptions listbox 保留独立模式）+ 侧栏底部快捷键提示行（三态文案组件；
  Web 当前两态可达，搜索态待 Web 搜索特性；单一常量源、`aria-hidden`）。

### Changed
- TUI 搜索改防抖 150ms 服务端查询（旧内核无 `total` → 自动降级 depth-8 本地过滤）；
  展开态键改为会话有效 `project_root`（`session/new` / `session/status` 加性
  `project_root` 捕获，未知回退 `__default__`）。

- `file/list` 参数 `query` + 结果 `total`。
- `SessionNewResult` / `SessionStatusResult.project_root`。
