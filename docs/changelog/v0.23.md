## 0.23.0 —— 右边栏运行详情（功能，七处加性 wire）

### Added
- **协议 `PROTOCOL_VERSION` 0.14.0 → 0.15.0**：
  - `FileChange { run_id/seq/source/total_bytes }`（`FileChangeSource = write|bash` +
    `Unknown`；`total_bytes` 仅在 `diff_truncated: true` 时出现）。
  - 外层 `ProgressValue::Todo/FileChange { run_id }`（路由提示）。
  - `TrajectoryValue::Todo/FileChange { run_id }`。
  - `SessionHistoryParams { run_id? }`（非法 → `-32602` + `data{reason:"invalid_run_id"}`；
    先过滤 Todo/FileChange 再 cursor/limit 分页，其余 kind 全量）。
  - `SessionRunResult { run_id? }`（去重键 `path` → `(run_id, path)`，`revision` 按 run 单调）。
- 内核：`TurnRunner` per-run UUID（`Uuid::new_v4`）+ `todo_revisions` / `file_change_seqs`
  `HashMap<String, u64>`（UUID 键全局唯一）+ `Done { run_id }` +
  `FileChangeArtifact { run_id/seq/source/total_bytes }`（write 截断 64 KiB 前缀 +
  total_bytes；bash 经 `git_sample` 标记 `source = bash`）。
- IPC：`broadcast` `sanitize_run_id`（非法 → None，不报错）+ `file_change_into_wire`
  透传 run_id/seq/source/total_bytes + trajectory 落盘 run_id +
  `dispatch_session_history` run_id 过滤 + `SessionRunResult.run_id` 回显。
- SDK：`parseProgress` 容忍非法 run_id / 未知 source / 旧数据缺字段；config
  VERSION 0.23.0 / PROTOCOL 0.15.0。
- Web：`todoState` 按 `(run_id, revision)` 丢旧帧 + `byRun` Map；`changes` 按
  `(run_id, path)` upsert + `sortBySeq`；`RightPanel` 按 run 分组（当前置顶 / 8-char
  short id / 未分组（历史））；`ChangeList` source 徽标 + 截断 hint「已截断（原始 N KiB）」+
  历史抽屉按 `seq`；`App` 捕获 `SessionRunResult.run_id` + `session/history { run_id }`
  过滤 + FileTree 跳转高亮。
- TUI：`TodoBlock` 兼容 run_id（新建 `todo.ts` 委托，per-run when runId else legacy）。
- 文档：`docs/specs/ipc-protocol.md` 同步 0.15.0 + 52 schemas + §7.3/8.7/8.19/9.1 更新。
