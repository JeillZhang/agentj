## 0.24.2 —— 右栏遮挡修复（修复）

用户直报「拖拽右边栏运行详情展宽时，文字逐渐被中栏右侧遮挡」。

### Fixed
- 右栏运行详情文字被中栏盖住（遮挡量随拖拽宽度线性增长）。三层根因与修复：
  1. `WorkspaceShell` 中栏 `.aj-shell__center { flex: 1 1 auto }` 基准取内容宽度，
     长代码块/宽工具卡把 flex 行撑破 → 改为 `flex: 1 1 0`（基准 0，只取剩余空间）。
  2. 行溢出时右栏 `.aj-shell__right { flex: 0 1 auto }` 被压缩到 `--aj-right-w` 以下 →
     改为 `flex: 0 0 auto`（拖拽宽度不可压缩；`flex-basis` 仍为 `auto`，
     v0.16.5 折叠揭示动画零回流保持不变）。
  3. 内层 `.aj-right` 宽度固定为 `--aj-right-w` + `align-self: flex-end` 右缘锚定，
     左侧溢出被 `overflow: hidden` 裁剪，又因中栏 `position: relative` 绘制在其上。
- 新增 CSS 契约守卫测试，禁止回退 `0 1 auto` / `1 1 auto`。

### Verified
- 实机 Chromium：1024/1100/1280/1440 视口 × 中栏 1600px 超宽内容拖拽 8 帧，遮挡帧 6 → 0。
- 折叠/展开 16 帧内层宽度恒定（零回流保持）。
- web 610 → 611 tests（52 files）。

## 0.24.0 —— 中栏 Composer 滚动自动收缩（功能）

### Added
- `composerCollapse.ts` 纯状态机：上滚离开底部（距底 >48px）自动收缩、下滚回底（<40px）
  自动展开；260ms 动画锁 + 8px 迟滞带（48/40）+ 迁移守卫；7 测。
- `ConversationFeed` 用户意图双判：`wheel`/`touchmove` 手势 + 非程序化 `scroll` 方向；
  程序化 `scrollIntoView` 自标记排除；5 测。

### Changed
- `RunPanel` 接线 `data-collapsed` + 发送按钮双职责（收缩态变「展开输入框」`ChevronsUp`，
  X/Y 零位移 + `aria-label`/`aria-expanded`/`aria-controls` 同步）；10 测。
- 收缩态：点击展开聚焦 textarea（`preventScroll`），自动展开不抢焦点；草稿全程保留；
  待答提问强制展开；收缩期冻结 `--aj-composer-h`（滚动几何稳定，无 scrollTop 钳制/振荡）；
  收缩同时关闭 composer 弹层；`ComposerOptions` 新增 `collapsed` prop。
- `composer.css` 分段收拢契约（header / 输入区 / 选择器收拢、按钮行保持）；reduced-motion
  复用既有双层机制；4 测。
- 评审修复波：延迟 visibility 切换修复真实浏览器「点击展开聚焦 textarea」；展开期
  `--aj-composer-h` settle 保持；锁过期回底重判；程序化标记仅 `delta >= 0` 消耗
  （不吞真实上滚）；header 展开上限 120px；3 回归测 + freeze 测试强化。
