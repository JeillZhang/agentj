## 0.25.0 —— opencode-go 订阅接入（一期）（功能）

把 OpenCode Go 订阅作为一等 provider：凭据落盘、动态目录、合规请求头、模型可见性。

### Added

- **新 crate `agentj-auth`（第 18 个）**：`Credential`（`api_key` / `oauth` 占位）+
  `AuthStore`（XDG 路径、目录 `0700` / 文件 `0600`、临时文件 + fsync + rename 原子写、
  权限与 JSON 校验拒绝降级）+ `resolve_credential`（`--api-key` > `api_key_env` >
  `auth.json`，绝不返回空串）+ `redact`（仅末 4 位；短密钥折叠为 `…`）。
- **`agentj auth login|status|logout`**：`--provider` / `--api-key` 或 stdin 管道 /
  `--default-model`（toml_edit 定点写回 `[model]`，保留注释）/ `--offline`（零网络）。
- **动态模型目录**：`fetch_live_models`（`GET /zen/go/v1/models`，5s 超时）+
  `ModelCatalog::from_sources`（live ∩ overlay；未知 ID 合成为 `openai-compat` 且
  `verified = false`；live 失败回退 overlay）+ `bin/gen_opencode_catalog`（overlay
  生成器，`--check` 校验过期）。
- **合规请求头**：全部 provider 统一 `User-Agent: agentj/<版本>`；opencode-go 在
  会话 ID 存在时携带 `x-opencode-session`（仅该 provider）。
- **模型可见性**：`ModelProvider::models()` 默认方法与 `ProviderRegistry::list_with_models()`
  （加性、零破坏）；`kernel/status` 填充既有 `providers[].models` 字段（零协议变更）；
  Web composer 与 TUI 模型视图消费真实列表并高亮 `default_model`（无数据保留原回退）。
- **网关错误解析**：`parse_gateway_error` 将 `{"type":"error","error":{type,message}}`
  渲染为 `类型: 消息`；401/403 附带 `agentj auth login` 提示；openai-compat 补齐
  `Retry-After` 解析（与 anthropic/responses 行为一致）。
- **可行动启动错误**：无法解析密钥的真实 provider 不再注册（消除空 `Bearer`），
  无任何可用 provider 时硬错误 `no usable model provider`。

### Changed

- CLI provider 装配改为 `build_providers`：凭据解析 → 目录构建 → 跳过无密钥 provider，
  并按来源（Flag/Env/File）+ 末 4 位打印 provenance 行（永不打印完整密钥）。
- 工作区版本 0.24.2 → **0.25.0**（功能 = minor）；desktop 三清单与 `check-version.sh` 同步。
