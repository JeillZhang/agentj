# v0.26.x —— 运行期切模型（`session/run` 加性参数）

> 发布：0.26.0（2026-10-07，功能）
> 协议：`PROTOCOL_VERSION` **0.15.0 → 0.16.0**（`session/run` 两个加性可选字段；
> 21 方法 / 52 schemas 不变，仅 `SessionRunParams.json` 内容更新）

## 0.26.0 —— 运行期切模型（功能）

让客户端在**运行期**按轮次选择模型：`session/run` 新增两个可选参数，内核在每轮 run 解析；
Web composer 与 TUI `/models` 的模型选择器接入选中的 provider / model。

### Added

- **`session/run` 加性参数 `provider` / `model`**（`@since 0.16.0`，snake_case，均可选）：
  `provider` 为**已注册** provider 名（= `kernel/status.providers[].id`，如 `opencode-go`），
  `model` 为模型 id（如 `opencode-go/kimi-k3`）。省略 / `null` / 空串或纯空白 = 今天行为
  （provider 走 `get_default()`、model 走 `config.model.default_model`）；覆盖**只作用于显式给出的
  维度**（只给 `provider` 时模型仍取配置默认，只给 `model` 时 provider 仍取内核默认），
  两者均为**按 run** 生效（不写会话快照、不改 `SessionRunResult`、不回显生效模型）。
  未携带这两个字段的请求 wire 与运行行为与今天逐字相同。
- **失败可行动**：非字符串类型（数字 / 对象 / 数组）→ `-32602`，`error.data` 携带
  `{ "field": "provider" | "model" }`；未知但格式合法的 provider 名 → 本轮运行失败
  （与今天 `no default provider` 同一 turn 错误通道），文案含 `unknown provider: <name>` 与
  已注册 provider 名列表，**不回落默认 provider**；不属于所选 provider 的 `model` 沿用既有
  `UnknownModel` 路径。
- **Web 运行期切模型**：composer 模型弹层选中项成为单一真源（修「选择被 props 覆盖」缺陷），
  列表保留 provider 归属；选中后**下一次** `session/run` 携带 `provider` + `model`，
  未选择时不携带新字段；选择写入本地 `agentj.composer.model`。
- **TUI 运行期切模型**：`ModelSelector` 由只读升为可选择（`/models` 打开，`j/k`/`↑↓` 移动、
  `Enter` 确认）；发送点携带所选项的 `model` 与（若有）`provider`；移除「重启内核生效」文案。

### Changed

- `PROTOCOL_VERSION` `0.15.0` → **`0.16.0`**（`protocol/methods.json` 同步；方法数仍 **21**、
  schema 总数仍 **52**，仅 `schemas/SessionRunParams.json` 内容更新）；工作区版本
  `0.25.2` → **`0.26.0`**（功能 = minor），desktop 三清单与 `check-version.sh` 同步。
- 此前客户端零破坏：旧内核忽略未知字段 → 行为不变；旧客户端不传字段 → 仍走内核默认。
