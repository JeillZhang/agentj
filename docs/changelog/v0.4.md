# v0.4.x —— 守护内核（常驻 API 服务）与商用扩展

> 发布：0.4.0（2026-08-23，功能）→ 0.4.1（2026-08-30，修复）
> 协议：`protocol_version` **0.2.0**

## 0.4.1 —— 复审修复（修复）

### Changed
- 设计回填：① `session/run` 会重写 owner 并隐式订阅发起方（非 owner 亦可 run，只要无并发）；
  ② 新增 `Connection::writer()` 半连接写句柄拆分（`ConnectionWriter`），保证 idle 订阅者
  不丢广播；③ TCP 常驻下 `shutdown`/最后连接断开触发**全局**优雅关闭；④ `initialize`
  认证字段为 `InitializeParams.token`。

## 0.4.0 —— 守护内核 + 商用能力（功能）

### Added
- **多客户端常驻 TCP 内核**：`serve --port` / `run --attach` / `dashboard`。
- 统一 `Connection` 抽象（stdio 哨兵 / `TcpConnection` / `ConnectionWriter`）。
- 协议加性扩展：`session/subscribe` / `unsubscribe`、`$/progress` 广播、`origin_client`
  属主路由、`-32805` / `-32806`、`initialize` token / `connection_id` / `multi_client`。
- `agentj-stats` 用量钩子经 AgentLoop on-turn-complete 接线。

### Deferred
- WebSocket 网关与运行状态机/控制权转移为后续阶段预留（v0.10 落地 WebSocket）。

### Verified
- 工作区 0.3.1 → 0.4.0 → 0.4.1。
